# pdf-to-markdown — PDFはローカルで変換してから読む

PDFをそのままClaudeに読ませると、ページごとに画像・テキストの両方が入ってトークンを食う。
テキスト層のあるPDFは、ローカルツールで`.md`にすれば無料で、しかも軽くなる。
このスキルは「PDFの種類を見分けて、安く正確なツールを選ぶ」ための手順書。

## 手順

### 1. PDFの種類を見分ける（ツールは使い分ける）

| PDFの種類 | 見分け方 | 使うツール |
|---|---|---|
| テキスト層あり（PowerPointやWordから書き出したもの。講義スライド、論文の大半） | `pymupdf` で1ページあたり数百字以上取れる | **PyMuPDF4LLM**（同梱の `scripts/pdf2md.py`） |
| スキャン・画像のみ | テキストがほぼ0字（スクリプトが「要OCR」と警告する） | OCR（`tesseract` / `ocrmypdf` など）→それでも崩れるページだけ画像として目視 |
| 数式・表が多く構造が崩れる論文 | 変換結果の表や式が壊れている | `marker-pdf` や `docling`（重い。必要なときだけ入れる） |
| 図・グラフの内容そのものが必要 | 本文に図の説明が無い | 該当ページだけ画像として見る（全ページは見ない） |

LLMに読ませるのは**最後の手段**。変換結果で足りない箇所だけ、ページを絞って画像で確認する。

### 2. 変換する

```bash
pip install pymupdf4llm        # 初回のみ
python -I <このスキルのパス>/scripts/pdf2md.py <PDFのフォルダ> -o <出力先フォルダ>
```

- 入力にはフォルダかPDF1つを渡す。フォルダなら直下の `*.pdf` を全て変換する（`-r` で再帰）
- 出力先を省略すると、入力フォルダ直下の `md/` に出る
- `.md` の更新日がPDFより新しいものはスキップする（`--force` で再変換）
- ページごとに `<!-- page N -->` が入る。後から「第3回の12ページ」のように遡れる
- `--images` で埋め込み画像をPNGで書き出す（普段は不要）

**出力先は、Classroom同期などの自動処理が走るフォルダの外に置く。** 元のPDFフォルダに書き込むと同期の対象になることがある。授業ごとのフォルダに `md/` を作るのが扱いやすい。

### 3. 変換結果を確かめる

スクリプトの最後に出る「[要OCR/目視]」の一覧を見る。ここに出たページは本文が取れていない。
まず1ファイルだけ先頭を読み、見出し・表・箇条書きが崩れていないかを確認してから、全体を信頼する。

### 4. 以後は.mdだけを参照する

- レポートや要約を書くときは、元のPDFを開き直さず、`.md` を `Grep` で絞り込んでから、必要な範囲だけ `Read` する
- `_講義前` と `_講義後` のように同じ回の版が複数あるときは、日付の新しい版（空欄が埋まった版）を正とする
- 引用や数値は、`.md` のページ番号コメントを使って「第N回 pM」と出典を付ける
- スライドは空欄補充形式のことがある。講義前版の空欄は、講義後版か写真・ノートで埋める。**推測で埋めない**

## 注意

- 日本語PDFで文字化けしたら、そのPDFはフォント埋め込みの問題。OCRに切り替える
- Google Drive上のPDFは初回アクセスが遅い（ストリーミング）。実測で約30ページ×6本が26分かかった（CPU時間は数秒で、待ちはほぼ読み込み）。バックグラウンドで走らせるか、先にローカルへコピーしてから変換する。2回目以降は`.md`が新しければスキップされる
- Windowsでは標準出力が文字化けすることがある。スクリプトは UTF-8 で出力する設定済み。それでも崩れたら `PYTHONUTF8=1` を付ける
