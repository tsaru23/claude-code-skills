# チャネル別ガイド

各チャネルの「始めるための前提」「向き・不向き」「最初にやること」をまとめる。
数値の目安と全体戦略は `playbook.md` を参照。

## 有料広告

### X広告

| 項目 | 内容 |
|---|---|
| 前提 | **X Premium(ブルーバッジ)の契約が必要**。未契約だと広告配信できない |
| 配信面 | X タイムライン |
| 向くもの | テキスト+静止画で価値が伝わるもの、開発者・ガジェット・生産性系 |
| 設定 | オートターゲティングがあるため、細かいターゲティング設定は必須ではない |

**キャンペーン目的の選び方**

- 「アプリのインストール」目的が使えればそれが最短。ただしストアからアプリが
  検索できない等で選べないことがある。
- その場合は **ウェブサイトトラッキング(サイト誘導)** に切り替え、
  ランディングページ経由でストアに送る。
- 「ブースト」機能もあるが、決済登録などで詰まることがある。

### Meta広告(Facebook / Instagram / Threads)

| 項目 | 内容 |
|---|---|
| 前提 | **ビジネスアカウントを作れば誰でも配信できる**(バッジ課金なし) |
| 配信面 | Facebook / Instagram / Threads にまとめて配信できる |
| 向くもの | 静止画・カルーセルで伝わるもの。生活寄り・一般向けプロダクト |
| 設定 | 自動ターゲティングあり。ダッシュボードに癖があるので慣れが必要 |

初めて広告を触るなら、バッジ課金が不要な **Meta広告から始めるのが入りやすい**。

### TikTok広告

| 項目 | 内容 |
|---|---|
| 向くもの | 動きで魅力が伝わるもの(ゲーム、アニメーション、操作の気持ちよさ) |
| 素材 | 実操作の画面録画、AI生成のUGC風動画、画像スライド |

### YouTube広告

| 項目 | 内容 |
|---|---|
| 向くもの | 動画で機能を説明する必要があるもの、単価が高いプロダクト |
| 注意 | 動画制作コストが他媒体より高くなりやすい |

### 広告を出す前のチェックリスト

- [ ] 訴求軸(誰の何の困りごとを、どう解決するか)が1文で書けているか
- [ ] クリエイティブ案を2案以上用意して比較できるか(A/Bテスト)
- [ ] 遷移先(ストアページ / LP)は整っているか。広告で来た人が離脱しない状態か
- [ ] 予算上限を設定したか(**金額はユーザー本人が確認・設定する**)
- [ ] 成功基準のCPAを事前に決めたか
- [ ] 停止の判断基準(いくら使って結果が出なければ止めるか)を決めたか

## SNS運用(無料)

### X

- ゼロから立ち上げやすい。開発者・個人開発界隈のコミュニティが機能している
- **プロフィールにプロダクト名+説明+リンク**を必ず設置(流入の受け皿)
- 日次ルーティン例(30分):
  1. ターゲット層の投稿を検索 → いいね・コメント・フォロー(手動、無差別にしない)
  2. 引用リポストで感想付きの反応を1〜2件
  3. build in public 投稿を1件(実装した機能 / 数字の節目 / 詰まった点と解決)
- 投稿文の作成は **sns-post-writer スキル**に委譲する

### Instagram / Threads

- ビジュアルが強いプロダクト向き。X運用の片手間だと稼働が落ちやすいので、
  主軸をどれか1つに決める

### TikTok

- 動画と**画像スライド(複数画像投稿)**の両方を試す。画像スライドのほうが
  伸びる場合がある
- 1本当たったら他SNSへ横流しする

### やってはいけない運用

- 無差別な大量フォロー / アンフォロー、自動DM、AIによるリプライ全自動化
- 複数アカウントでの自作自演、レビューの購入・見返り付き依頼

## 共有機能・バイラルデザイン(無料)

実装の観点:

- **シェアボタン**: OS標準のシェアシート、リンクコピー、SNS別のシェアURL
- **シェア対象**: ユーザーが作った記録・コンテンツ・集計結果
- **画像生成シェア**: 共有用の画像をアプリ内で生成すると拡散力が上がる
  (アプリ名・ロゴを自然に含める)
- **プライバシー**: 金額や個人情報をマスクする / 表示を選べるようにする
- **計測**: シェア経由の流入が分かるよう、共有URLにパラメータを付ける

「スクショされる画面」の設計チェックは `playbook.md` の該当節を参照。

## SEO / LLMO(無料)

### 立ち上げ手順

1. **キーワードの洗い出し**: ターゲットが検索するワードをカテゴリごとに列挙する
2. **記事リスト作成**: 1キーワード1記事。まず20〜50本のリストを作り、
   ユーザーの承認を得る
3. **記事生成**: AIで生成してよい領域。ただし内容の事実確認は行う
4. **導線設置**: 記事中・記事末にプロダクト紹介と導線を入れる
5. **待つ**: インデックスと順位上昇に2〜3ヶ月

### LLMO(AI検索対策)

- 構造化データ・メタデータを整える
- 「何ができるツールか」を曖昧さなく明記したページを用意する
- 比較・使い方・ユースケースなど、AIが引用しやすい形式の記事を用意する

## ASO(App Store / Google Play 最適化)

### 優先順位

1. **スクリーンショット1〜2枚目** — 最も影響が大きい
2. **社会的証明の表示** — 実績のある数字のみ(虚偽表示は禁止)
3. **キーワード・カテゴリ・メタデータ**
4. **アップデート頻度**

### スクリーンショット構成の型

| 枚目 | 内容 |
|---|---|
| 1 | 一番の価値が伝わる画面 + 短いキャッチコピー |
| 2 | 社会的証明(実績値)またはサブの主要機能 |
| 3〜 | 個別機能、使い方の流れ |

キャッチコピーはスマホの一覧表示で読めるサイズか必ず確認する。

### レビュー

- レビュー依頼のポップアップは、ユーザーが成功体験を得た直後に出す
- **レビューの購入・見返り付き依頼はしない**(規約違反)

## オフライン・その他

- 知人・友人との会話でその課題が出たら紹介する。インストールまでの距離が近く、
  そこから知り合い伝いに広がる可能性がある
- 新しいプラットフォームやコミュニティを見つけたら、まず1回試す
  (ただし各コミュニティの宣伝ルールを必ず確認し、規約違反の投稿はしない)
